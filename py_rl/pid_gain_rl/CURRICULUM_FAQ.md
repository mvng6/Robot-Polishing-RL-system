# ❓ 커리큘럼 학습 FAQ

## Q1: 단계를 올릴 때마다 계속 actor/critic의 신경망을 전이학습하면서 가는거야?

**답변: 네, 맞습니다!** 

각 Phase 전환 시 **전이학습(Transfer Learning)**을 수행합니다.

### 전이학습 프로세스:

1. **Phase 1 완료**
   ```
   학습 완료 → 모델 저장
   saved_agents/phase_1_best.pth
   (Actor + Critic 가중치 포함)
   ```

2. **Phase 2 시작**
   ```python
   # 이전 모델 로드
   python3 main.py --load-model saved_agents/phase_1_best.pth --curriculum-phase 2
   
   # 또는 코드 내에서 자동 로드
   agent.load_checkpoint("saved_agents/phase_1_best.pth")
   ```

3. **Phase 2 학습**
   - Phase 1의 Actor/Critic 가중치를 **초기값으로 사용**
   - 새로운 환경(-35N~-50N 무작위)에서 **추가 학습** (150-200 에피소드)
   - 기존 지식 재사용 + 새로운 상황 적응

4. **Phase 2 완료 → Phase 3 시작**
   - Phase 2 모델 로드 → Phase 3 학습
   - 반복...

### 전이학습의 장점:

✅ **빠른 수렴**: 처음부터 학습하지 않고 기존 지식 활용  
✅ **안정적 학습**: 이전 Phase에서 안정화된 가중치로 시작  
✅ **점진적 적응**: 점진적으로 난이도 증가에 자연스럽게 적응  

### 구현 예시:

```python
# env.py 또는 main.py에서
if config.curriculum_phase > 1:
    # 이전 Phase 모델 로드
    prev_phase_model = f"saved_agents/phase_{config.curriculum_phase - 1}_best.pth"
    if os.path.exists(prev_phase_model):
        print(f"🔄 Phase {config.curriculum_phase - 1} 모델 로드 중...")
        agent.load_checkpoint(prev_phase_model)
        print("✅ 전이학습 시작 (이전 모델 기반)")
    else:
        print("⚠️ 이전 모델 없음, 처음부터 학습")
```

## Q2: 단계가 점점 높아질수록 완료 조건의 평균 보상이 낮아지는데 왜 그런거야?

**답변: 제가 잘못 설정했습니다! 수정했습니다.** 

### ❌ 기존 계획 (잘못됨):

- Phase 1: 평균 보상 > 0.5
- Phase 2: 평균 보상 > 0.3  ← 점점 낮아짐
- Phase 3: 평균 보상 > 0.2
- Phase 4: 평균 보상 > 0.15
- Phase 5: 평균 보상 > 0.1

### ✅ 수정된 계획 (올바름):

- Phase 1: 평균 보상 > 0.5
- Phase 2: 평균 보상 > 0.4  ← 유사한 수준 유지
- Phase 3: 평균 보상 > 0.35
- Phase 4: 평균 보상 > 0.3
- Phase 5: 평균 보상 > 0.25

### 왜 이렇게 수정했나요?

1. **전이학습 효과**: 이전 Phase에서 학습한 지식을 활용하므로 충분히 학습하면 **비슷한 성능** 달성 가능

2. **일반화 능력**: 다양한 목표에 대한 일반화를 학습하면, 각 목표에 대해 **고정 목표만큼의 성능**을 낼 수 있음

3. **동적 환경의 어려움**: Phase 3+에서 목표 변경이 있지만, 충분한 학습 후 **적응 능력**을 갖추면 비슷한 보상 가능

4. **실제 성능 기준**: 모든 Phase에서 **실용적인 수준의 성능**을 기대해야 함

### 완료 조건이 약간 달라지는 이유:

- **Phase 1**: 고정 목표 → 가장 쉬움 → 높은 보상 기대 가능
- **Phase 2**: 무작위 목표 → 일반화 필요 → 약간 낮을 수 있음 (0.4)
- **Phase 3+**: 동적 환경 → 적응 속도 평가 → 약간 낮을 수 있음 (0.3-0.35)

하지만 **충분히 학습하면** Phase 1 수준에 근접할 수 있습니다!

### 추가 고려사항:

완료 조건에 **구간별 성능**도 고려:

```python
# Phase 4 예시
완료 조건:
- 구간 1 (0~10초): 평균 보상 > 0.3
- 구간 2 (10~20초): 평균 보상 > 0.3
- 구간 3 (20~30초): 평균 보상 > 0.3
- 목표 변경 후 1.5초 내 적응 (추가 평가)
```

이렇게 하면 **동적 환경에서도 각 구간마다 좋은 성능**을 기대할 수 있습니다.

## 💡 결론

1. **전이학습**: 각 Phase 전환 시 이전 모델을 로드하여 연속 학습
2. **완료 조건**: 모든 Phase에서 유사한 수준의 성능 기대 (충분히 학습 시)
3. **점진적 난이도**: 난이도는 올라가지만, 전이학습으로 충분한 성능 달성 가능
