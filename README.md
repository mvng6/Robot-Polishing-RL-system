# 강화학습 기반 로봇 폴리싱 정밀 힘 제어 시스템

## 📝 프로젝트 개요

본 프로젝트는 협동로봇과 공압 샌더를 이용한 **자동화 폴리싱 공정**을 위한 **강화학습 기반 정밀 힘 제어 시스템**입니다.

기존의 PID 제어기가 가진 한계를 극복하고, 다양한 형상의 작업물에 대해 일정한 접촉력을 유지하기 위해 **C++로 구현된 실시간 로봇 제어 클라이언트**와 **Python으로 구현된 강화학습(Soft Actor-Critic, SAC) 서버**가 연동하여 동작합니다.

Python RL 에이전트는 로봇의 상태(접촉력, 오차 등)를 실시간으로 받아 **최적의 보상 압력(Residual Pressure)**을 계산하여 C++ 클라이언트로 전송하고, 클라이언트는 이 값을 PID 제어 출력에 더하여 공압 샌더의 접촉력을 정밀하게 보정합니다.

<br>

## ✨ 주요 특징

* **하이브리드 제어 시스템**: 안정적인 **PID 제어**와 지능적인 **강화학습(SAC) 제어**를 결합하여 강인하고 정밀한 힘 제어를 구현합니다.
* **잔차 학습 (Residual Learning)**: RL 에이전트는 전체 제어 출력이 아닌, PID 제어기의 오차를 보상하는 '잔차(Residual)' 값만 학습합니다. 이를 통해 학습의 안정성과 효율성을 크게 향상시켰습니다.
* **실시간 멀티스레드 아키텍처 (C++)**: `서보 제어`, `FT 센서`, `공압 제어`, `로봇 구동`, `데이터 로깅` 등 주요 기능이 독립된 스레드에서 병렬로 동작하여 실시간성과 안정성을 보장합니다.
* **고급 보상 함수 설계**: 단순한 보상 함수를 넘어, `다층 보상`, `지수적 보상`, `커리큘럼 학습` 등 다양한 고급 보상 공학 기법을 체계적으로 연구하고 적용할 수 있는 기반(`reward_engineering_course.py`)을 포함합니다.
* **실제 하드웨어 연동**: 두산 협동로봇, FT 센서, NI-DAQmx 기반 공압 제어 시스템과의 연동을 통해 실제 산업 현장에 적용 가능한 솔루션입니다.

<br>

## ⚙️ 시스템 아키텍처

본 시스템은 실시간 제어를 담당하는 C++ 클라이언트와 학습 및 추론을 담당하는 Python 서버로 구성되며, TCP/IP 소켓 통신을 통해 데이터를 교환합니다.
```
+------------------------------------------+                      +-----------------------------------------+
|        Robot Control PC (Client)         |                      |          RL Agent PC (Server)           |
|      (C++ / MFC / Real-Time Control)     |                      |     (Python / PyTorch / SAC Agent)      |
+------------------------------------------+                      +-----------------------------------------+
|                                          |                      |                                         |
|   [ Doosan Robot Controller ]            |                      |                                         |
|   [ FT Sensor ]                          |                      |                                         |
|   [ Pneumatic Sander (NI-DAQmx) ]        |                      |                                         |
|                                          |                      |                                         |
|                  +------------------+    |                      |    +--------------------------------+   |
|                  | PID Force        |    |                      |    |       Soft Actor-Critic        |   |
|                  | Controller       |    |                      |    |             (SAC)              |   |
|                  +------------------+    |                      |    +--------------------------------+   |
|                          |               |         State        |                      ^                  |
|                   (Base Pressure)        |  (Force, Error, etc.)|                      |                  |
|                          |               |--------------------->|               (Reward Calc)             |
|                          v               |                      |                      |                  |
|   +-----------+ <---(+)---> +----------+ |                      |    +-----------------+---------------+  |
|   | Final     |      ^      | Residual | |      Residual        |    | Replay Buffer & Policy Update   |  |
|   | Pressure  |      |      | Pressure | |       Action         |    +---------------------------------+  |
|   | Command   |      |      | (from RL)| | <--------------------|                                         |
|   +-----------+      +      +----------+ |                      |                                         |
|       |                                  |       TCP/IP         |                                         |
|       v                                  |                      |                                         |
|   [ Pneumatic Actuator ]                 |                      |                                         |
|                                          |                      |                                         |
+------------------------------------------+                      +-----------------------------------------+
```

## 🛠️ 기술 스택 및 환경

### C++ 클라이언트 (`cpp_controller`)

* **언어**: C++
* **프레임워크**: MFC (Microsoft Foundation Classes)
* **개발 환경**: Visual Studio
* **주요 라이브러리/SDK**:
    * Doosan Robotics DRFLEx SDK (두산 협동로봇 제어)
    * NI-DAQmx (공압 비례 압력 밸브 제어)
    * VCI SDK (FT 센서 데이터 수집)
* **역할**: 하드웨어 실시간 제어, 센서 데이터 수집, PID 힘 제어, Python 서버와 TCP/IP 통신

### Python 서버 (`py_rl`)

* **언어**: Python
* **개발 환경**: Visual Studio Code, PyCharm 등
* **주요 라이브러리**:
    * PyTorch (신경망 및 강화학습 구현)
    * NumPy (데이터 처리)
    * Matplotlib, Pandas (데이터 로깅 및 분석)
* **알고리즘**: **SAC (Soft Actor-Critic)**
* **역할**: 강화학습 에이전트 학습 및 추론, C++ 클라이언트와 TCP/IP 통신

## 🚀 실행 방법

1.  **Python RL 서버 실행**
    * `py_rl` 폴더로 이동하여 가상환경을 설정하고 필요한 라이브러리를 설치합니다.
        ```bash
        pip install torch numpy matplotlib pandas
        ```
    * Python 스크립트를 실행합니다. 서버는 C++ 클라이언트의 연결을 대기 시작합니다.
        ```bash
        python JY_Pneumatic_SAC_Pre_only_test_6_1000Hz.py
        ```

2.  **C++ 제어 클라이언트 실행**
    * `cpp_controller` 프로젝트를 Visual Studio에서 열고 컴파일합니다. (두산로봇, NI, FT센서 SDK가 시스템에 설치 및 연동되어 있어야 합니다.)
    * `Robot_Comm_SW_DJ_v5Dlg.cpp` 파일 내의 로봇 및 Python 서버 IP 주소를 실제 환경에 맞게 수정합니다.
    * 컴파일된 실행 파일을 실행합니다.

3.  **시스템 연동 및 작업 시작**
    * C++ 클라이언트 GUI에서 **[로봇 연결]** 버튼을 눌러 로봇 제어기와 연결합니다.
    * **[TCP/IP 연결]** 버튼을 눌러 실행 중인 Python 서버와 연결합니다.
    * **[힘 제어 시작]** 버튼을 누르면 `Thread_Contact_Flat_RL` 스레드가 활성화되어 강화학습 기반의 폴리싱 작업을 시작합니다.
